# 规则、代码与描述核对（2026-09-26）

本轮重点检查卡片介绍、基础/扩展两个结算器的一致性、贵族与攻城开局时机、战车交互、夜幕及震慑已有联动测试。自动测试能验证列出的场景，不能证明所有组合都没有问题。

## 已修正

| 项目 | 原冲突 | 处理 |
|---|---|---|
| 战斗牧师存活条件 | 基础结算器在牧师被长枪兵反伤消灭后仍抽币；扩展结算器不抽，旧基础测试还要求抽币 | 按贵族 FAQ 的存活条件统一两套结算，并补上存活/阵亡对照测试；说明同步补充 |
| BP 的公共设置 | 法令、堡垒在 BP 完成后才随机生成，选兵时看不到 | 创建 BP 时确定并持久化；双方可查看法令说明和堡垒示意图；对局沿用同一设置 |
| 战车选择顺序 | 行动拆解先点目的地、再点友军，与推动顺序相反 | 先选相邻友军，再选其目的地；仍由服务端验证完整两步 |
| 步兵 | “同时部署两个单位”容易理解为一次部署两支 | 明确场上最多两支、每次部署一支；战术各执行一次普通调遣 |
| 劫掠者 | “增强后可移动”没有写明这是触发属性 | 明确每次增强后可免费移动一格、战术消耗自身增强币 |
| 火油投手 | 未写明招募的是本兵种、必须有已部署单位、震慑恰好两格 | 补齐介绍 |
| 工兵 | 未写明一步移动及堡垒供应条件 | 补齐介绍 |
| 刺客、渗透者、战车 | 移动距离简写；战车未强调必须完成跟进 | 明确一格移动；战车两步都要执行 |

牧师存活条件是根据贵族 FAQ 关于战斗牧师、狂战士、剑士的统一说明，应用到普通攻击后的结算；基础说明书没有单列牧师与长枪兵互灭的问答。

## 已有行为再次确认

- 无主堡垒可以攻击；堡垒保护格内敌军不依赖该格由谁控制。多格移动不能穿越堡垒。
- 攻城战术要求发动时已增强；攻城塔第一次攻击遭长枪兵反伤后只剩一枚，仍可继续第二次攻击。
- 战车代伤不能用于长枪兵反伤；代替被攻击长枪兵承伤也不会取消反伤。
- 法令的普通攻击不能绕过弓箭手、枪骑兵和投石机的攻击限制。
- 震慑不是攻击；敌军在堡垒内免疫震慑。重骑兵战术须直线恰好两格；先锋须已增强。

## 与官方组军规则的差异

这些属于现有组军流程，不能描述成完全复刻官方选兵。

- 本项目采用用户指定的十选八 Ban/Pick 顺序，并允许取消基础版。当前 BP 先选方也是对局先手；官方基础高级选兵则由后选方先行动。本轮保留现有流程。
- 替代兵种当前按共用币的类别去重，候选池只显示原版或替代版中的一个。官方震慑规则是在两张都抽到时将其配对、补抽另一张，并由取得这对卡的玩家选择版本。当前的去重能防止两方占用同一类实体币，但缺少官方的版本选择步骤；本轮记录这一差异，未将其混入规则结算修复。
- 更新前已经开始 BP 的旧房间没有预先公开的设置；兼容读取这些房间，完成 BP 时继续原有初始化方式。新房间及再战使用新流程。
